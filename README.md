# Invent a Word We Need

One coined word for a feeling English has no name for: *planlief* — the quiet relief of a plan being cancelled, sweetest when you were already dressed to go out. The dread of going out flips to relief in a single message, and being already dressed makes the relief sharper, not weaker. Built from familiar parts (plan + relief), so it is sayable, spellable and easy to remember, and the definition lands in one reading.

## Run it

```sh
python3 main.py
```

Writes one line (104 characters, UTF-8) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` if that variable is unset. Python 3 standard library only, no network, deterministic.
